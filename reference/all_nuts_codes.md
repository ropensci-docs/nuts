# List of all NUTS codes and classifications

The data frame stores all NUTS codes in hierarchical levels 1, 2 and 3
by NUTS classification versions 2006, 2010, 2013, 2016, 2021 and 2024.

## Usage

``` r
all_nuts_codes
```

## Format

### `all_nuts_codes`

A data frame with 10,465 rows and 3 columns:

- code:

  NUTS code

- version:

  NUTS versions

- country:

  Country name
