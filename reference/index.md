# Package index

## Workhorse Functions

Functions that classify and convert regional data

- [`nuts_aggregate()`](https://docs.ropensci.org/nuts/reference/nuts_aggregate.md)
  : Aggregate to higher order NUTS levels
- [`nuts_classify()`](https://docs.ropensci.org/nuts/reference/nuts_classify.md)
  : Classify version of NUTS codes
- [`nuts_convert_version()`](https://docs.ropensci.org/nuts/reference/nuts_convert_version.md)
  : Convert between NUTS versions

## Additional Functions

Helper functions to classify and convert regional data

- [`nuts_get_data()`](https://docs.ropensci.org/nuts/reference/nuts_get_data.md)
  : Return classified NUTS data
- [`nuts_get_missing()`](https://docs.ropensci.org/nuts/reference/nuts_get_missing.md)
  : Return missing NUTS codes in classified NUTS data
- [`nuts_get_version()`](https://docs.ropensci.org/nuts/reference/nuts_get_version.md)
  : Return version overlap of classified NUTS data
- [`nuts_test_multiple_versions()`](https://docs.ropensci.org/nuts/reference/nuts_test_multiple_versions.md)
  : Helper function to test for multiple versions

## Data

Data sets required for conversion and examples

- [`all_nuts_codes`](https://docs.ropensci.org/nuts/reference/all_nuts_codes.md)
  : List of all NUTS codes and classifications
- [`cross_walks`](https://docs.ropensci.org/nuts/reference/cross_walks.md)
  : Conversion table provided by the Joint Research Center of the
  European Commission
- [`manure`](https://docs.ropensci.org/nuts/reference/manure.md) :
  Manure storage facilities by NUTS 3 regions from Eurostat (aei_fm_ms)
- [`patents`](https://docs.ropensci.org/nuts/reference/patents.md) :
  Patent applications to the EPO by priority year by NUTS 3 regions
  (pat_ep_rtot)
